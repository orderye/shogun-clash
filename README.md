# 幕府争锋 · 网页版（可操作演示）

> 以 `shogun-clash/`（规则书 + 卡牌图鉴）为底本制作的**可视化可操作网页版**。
> 直接双击 `index.html` 即可在浏览器中游玩，无需安装任何依赖。

---

## 🎮 快速开始

1. 用浏览器打开 `index.html`
2. 自动开局：双方随机抽取天皇/将军（先手先抽、不可同卡）、各 5 张起手
3. 你（玩家）对战电脑（AI），轮流操作

## 🖱 操作说明

| 操作 | 方式 |
| --- | --- |
| 抽牌 | 顶部「抽牌（1 张）」（每回合一次） |
| 召唤武士 | 点击手牌中的武士卡（可一次召唤多只）；**所有单位召唤当回合即可攻击** |
| 献祭召唤 | 点击手牌中的大名/公卿卡 → 点击场上一位武士作为祭品（本回合新召唤的不可献祭） |
| 恩典召唤 | 连续 3 回合未召公卿/大名后，顶部出现「✨ 恩典召唤」按钮——可召唤手牌中的**大名或公卿**（无需献祭） |
| 放置城池/事件 | 点击手牌中的城池/事件卡（区内有牌会询问是否顶替） |
| 装备 | 点击手牌中的兵刃/装具/骑具 → 点击场上合法单位 |
| 宝物 | 点击手牌中的宝物卡 → 选择**装备于己方或对方天皇**（每位天皇 2 张；第一~三层目标加成、登场必发威压/苦肉、上场/下场增减；**满 2 张的回合结束更换天皇**） |
| 圣迹/灾厄 | 点击手牌中的圣迹/灾厄卡 → 弹窗查看详情并确认使用（代价：两回合不能攻击）；**对方攻击时若手中有此类牌，会弹出「是否消解」选择** |
| 战斗 | 顶部「⚔ 进入战斗」→ 点击己方单位 → 点击对方目标（只能攻击最前层；对方空场可直接点其将军） |
| 募兵 | 顶部「🏰 募兵」（己方王城/名城在区）：每三回合一次、扣 10/5 生命，己方无大名且无公卿时从手牌或弃牌堆召唤（王城：大名/公卿/武士；名城：公卿/武士），不减半 |
| 回收兑换 | 顶部「♻ 回收兑换」：3 张圣迹→回收弃牌堆 大名/公卿/武士；3 张城池→公卿/武士；3 张事件→武士 |
| 自愿下场/弃牌 | 场上单位卡右上「✕」→ 自愿下场入弃牌堆；手牌弹窗可选「弃置此牌」 |
| 结束回合 | 顶部「结束回合」 |

## 📜 已实现的核心规则

- 化身随机抽取（不可同卡）；共用卡组 170 张；开局 5 张手牌、每回合抽 1 张
- 前两回合不能攻击；**所有单位召唤当回合即可攻击**；每回合武士、公卿、大名各仅一位可攻击
- **战斗**：必定命中、攻击值点伤害；武士减防御/公卿减攻击/大名耗命值（替死 10+本命 10）；
  溢出伤害直击将军（可被将军躲避）；骑具躲避判定；将军技能（自疗/压制）、躲避率、增幅光环
- **天皇**：将军之佑（每回合回血）、武士之锋（武士攻+）、兵刃之锐、装具之固、骑具之灵、事件之速（部分）
- **城池**：城威全场攻防、上场敌方将军 −5、增幅（将军生命）
- **事件**：第一层全场攻防、第二层将军生命、第四层 破阵/暗杀
- **装备**：兵刃（大名/武士 +攻）、装具（大名/公卿 +防）、骑具（公卿/武士 躲避）
- 恩典召唤防死局；**三张换一回收**（圣迹/城池/事件）；战场区满员时献祭召唤可先下场武士再召大名/公卿；玩家可自愿下场单位、弃置手牌；手牌上限 8

## ⚠ 简化说明（相对规则书）

网页版为**核心可玩实现**，以下规则暂未完整实现（已标注或简化为基础效果）：
- 武士三层特效：已实现「战意」「坚守」「持刃」「骑术」；「事件立场（第三层）」未实现
- 城池募兵（王城/名城，每三回合一次）与**城池装备共鸣强化**（王城/名城兵刃双单位、敌方装具双单位、王城骑具双单位、大城兵刃 ±50/30%）已实装；
  大名四层特效、公卿城池加成、事件第五层 X/Y 清算、灾厄第二层灾殃等**多层卡牌特效**仍为简化处理
- 卡牌详情弹窗：**每一层、每一个特效均已逐条写清**；**天皇/将军/场上装备/宝物/常置牌均可点击查看**；**战报中 🔍 可查看相关卡牌详情**
- AI 会主动使用圣迹/灾厄（含消解）、事件/城池（含顶替对方常置牌）、宝物、募兵、恩典召唤与装备；
  **AI 每个操作间隔 2 秒**，带视觉特效（手牌高亮、单位闪光/抖动、伤害飘字、区域脉冲）

规则细节以 `shogun-clash/规则书.md` 与 `shogun-clash/卡牌图鉴.md` 为准。
