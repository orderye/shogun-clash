## 🎮 快速开始

1. 用浏览器打开 `index.html`（或直接访问[在线试玩](https://orderye.github.io/shogun-clash/)）
2. 自动开局：双方随机抽取天皇/将军（先手先抽、不可同卡）、各 5 张起手
3. 你（玩家）对战电脑（AI），轮流操作

## 🖱 操作说明

| 操作 | 方式 |
| --- | --- |
| 抽牌 | 顶部「抽牌（1 张）」（每回合一次） |
| 召唤武士 | 点击手牌中的武士卡（可一次召唤多只）；**所有单位召唤当回合即可攻击** |
| 献祭召唤 | 点击手牌中的大名/公卿卡 → 点击场上一位武士作为祭品（本回合新召唤的不可献祭） |
| 恩典召唤 | 连续 3 回合未召公卿/大名后，顶部出现「✨ 恩典召唤」按钮——可召唤手牌中的**大名或公卿**（无需献祭） |
| 放置城池/事件 | 点击手牌中的城池/事件卡（区内有牌会询问是否顶替） |
| 装备 | 点击手牌中的兵刃/装具/骑具 → 点击场上合法单位 |
| 宝物 | 点击手牌中的宝物卡 → 选择**装备于己方或对方天皇**（每位天皇 2 张；第一~三层目标加成、登场必发威压/苦肉、上场/下场增减；**满 2 张的回合结束更换天皇**） |
| 圣迹/灾厄 | 点击手牌中的圣迹/灾厄卡 → 弹窗查看详情并确认使用（代价：两回合不能攻击）；**对方攻击时若手中有此类牌，会弹出「是否消解」选择** |
| 战斗 | 顶部「⚔ 进入战斗」→ 点击己方单位 → 点击对方目标（只能攻击最前层；对方空场可直接点其将军） |
| 辅佐目标 | 点击己方大名卡上的「辅：XXX」徽标 → 点击一位己方武士（励武）/公卿（护卿）作为唯一指定目标（目标下场后自动改指） |
| 触发式选一单位 | 事件第三层（受创／敌攻／我攻）、宝物第一~三层指定、宝物第五层上场/下场、将军天赋、事件之速夺取、丰玉姬化龙、公卿城池加成替死、王城骑具躲避奖励：触发时弹窗**由你点选**具体单位；「我攻」先选**攻击 +1 / 防御 +1**再选单位 |
| 宝物改指 | 点击天皇下的宝物徽标 → 「🎯 重新指定武士/公卿/大名目标」（目标离场后需重指） |
| 骑具共享指定 | 己方王城在区时，装备骑具的单位卡上出现「共享：XXX」徽标 → 点击指定第二名受益者（或取消指定、恢复按战场区顺序配对） |
| 募兵 | 顶部「🏰 募兵」（己方王城/名城在区）：每三回合一次、扣 10/5 生命，己方无大名且无公卿时从手牌或弃牌堆召唤（王城：大名/公卿/武士；名城：公卿/武士），不减半 |
| 回收兑换 | 顶部「♻ 回收兑换」：3 张圣迹→回收弃牌堆 大名/公卿/武士；3 张城池→公卿/武士；3 张事件→武士 |
| 自愿下场/弃牌 | 场上单位卡右上「✕」→ 自愿下场入弃牌堆；手牌弹窗可选「弃置此牌」 |
| 结束回合 | 顶部「结束回合」 |

## 📜 已实现的核心规则

- 化身随机抽取（不可同卡）；共用卡组 185 张；开局 5 张手牌、每回合抽 1 张
- 前两回合不能攻击；**所有单位召唤当回合即可攻击**；每回合武士、公卿、大名各仅一位可攻击
- **战斗**：必定命中；**武士**以自身攻击值抵消、减防御值；**公卿**以自身防御值抵消、减攻击值；
  **大名**防御值作护盾（削防御 → 被穿透则扣命值、防御回满、弃装备、本阶段增幅失效），替死/本命各 10 点；
  溢出伤害直击将军（可被将军躲避）；骑具躲避判定；将军技能（自疗/压制）、躲避率、增幅光环
- **天皇**：将军之佑（每回合回血）、武士之锋（武士攻+）、兵刃之锐、装具之固、骑具之灵、事件之速（部分）
- **城池**：城威全场攻防、上场敌方将军 −5、增幅（将军生命/类型单位/装备，均为**常置光环**）、募兵（王城/名城，每三回合一次）
- **事件**：第一层全场攻防 + 装备共鸣（兵刃/装具成长概率）、第二层将军生命（**每回合开始结算**）、
  第三层 受创/敌攻/我攻/御守（触发时由玩家点选单位，我攻先选攻击或防御）、第四层 破阵/暗杀、第五层 X/Y 清算
- **多层单位特效**：武士三层特效（战意/坚守/持刃/骑术/事件立场）、大名四层（动态/辅佐/城盟/事件之势）、
  公卿城池加成 ①~⑥、灾厄五层（消解/灾殃/王座更迭/天罚/神迹克制）
- **装备**：兵刃（大名/武士 +攻）、装具（大名/公卿 +防）、骑具（公卿/武士 躲避），兵刃/装具**成长**（攻/防结算后掷骰 +1，永久）；
  王城在区时己方骑具**可同时作用于两名己方单位**（第二名受益者可点击指定，未指定时按战场区顺序配对），
  且躲避判定成功时敌方一位武士攻击 **+1**（永久，由攻击方点选受益武士）
- 恩典召唤防死局；**三张换一回收**（圣迹/城池/事件）；战场区满员时献祭召唤可先下场武士再召大名/公卿；玩家可自愿下场单位、弃置手牌；手牌上限 8

## ⚠ 简化说明（相对规则书）

网页版为**核心可玩实现**。**多层卡牌特效已按层实装**：武士三层（战意／坚守／持刃／骑术／事件立场）、
大名四层（动态／辅佐／城盟／事件之势）、公卿城池加成 ①~⑥、事件五层（含第一层装备共鸣、第二层天佑每回合、第三层触发式选一单位、第五层 X/Y 清算）、
灾厄五层（消解／灾殃／王座更迭／天罚／神迹克制）、城池五层（含第一层常置光环、第二层骑具共享与点击指定）、宝物五层（含第一~三层改指）、
圣迹（含八咫乌引路的「天皇/将军二选一」）。

规则书写「选一单位 / 指定一位」的地方均由玩家点选（AI 侧自动决策）：
事件第三层 受创／敌攻／我攻、宝物第一~三层指定与第五层上场/下场、将军天赋、事件之速夺取、丰玉姬化龙、
公卿城池加成替死（②弃哪位武士、③④⑤弃哪件装备）、王城骑具共享的第二名受益者、王城骑具躲避成功的受益武士。

以下规则**仍为简化或未实装**（界面与卡片详情中已如实标注）：

- 须佐之男斩杀八岐大蛇的「随机获得一张宝物牌」按规则书**随机**落在单位上，不由玩家挑选
- 卡牌详情弹窗：**每一层、每一个特效均已逐条写清**；**天皇/将军/场上装备/宝物/常置牌均可点击查看**；**战报中 🔍 可查看相关卡牌详情**
- AI 会主动使用圣迹/灾厄（含消解）、事件/城池（含顶替对方常置牌）、宝物、募兵、恩典召唤与装备；
  **AI 每个操作间隔 2 秒**，带视觉特效（手牌高亮、单位闪光/抖动、伤害飘字、区域脉冲）

规则细节以 `docs/规则书.md` 与 `docs/卡牌图鉴.md` 为准。

## 🧪 本地开发

游戏本体零依赖，但**测试与静态检查**需要 Node.js（CI 使用 Node 22）。

```bash
npm install        # 安装开发依赖（Vitest + ESLint）
npm test           # 运行测试套件（Vitest，11 个文件 / 251 个用例）
npm run lint       # 静态检查（ESLint）
```

测试通过在 Node 中复现浏览器的全局作用域来加载 `js/data.js` 与 `js/game.js`（`vm` context + 经典 `<script>` 语义），并注入 UI 桩与可播种的 PRNG，使洗牌与判定完全可重现——这是「黄金快照」用例成立的前提。

**持续集成**：[`.github/workflows/ci.yml`](.github/workflows/ci.yml) 在 `main` 分支 push / PR 时自动执行 `npm ci` → `npm run lint` → `npm test`。

**部署**：仓库已启用 GitHub Pages，每次推送 `main` 后自动重新发布至 <https://orderye.github.io/shogun-clash/>。

## 📂 项目结构

```
shogun-clash/
├── index.html          # 入口：化身抽选屏 → 对局界面
├── css/style.css       # 全部样式（含响应式布局与动画）
├── js/
│   ├── data.js         # 卡牌数据（205 张：天皇/将军各 10 + 共用卡组 185）
│   ├── game.js         # 核心规则逻辑，零 DOM 依赖
│   └── ui.js           # 渲染、交互与特效
├── docs/
│   ├── 规则书.md        # 完整规则（16 章）
│   └── 卡牌图鉴.md      # 全套卡牌数据
├── tests/              # Vitest 用例：smoke / golden / data / rules / stats / layers / choices
│                     #   + win（胜负判定） / rules-audit（规则书逐条核对）
│                     #   + data-audit（卡牌数据体检） / invariants（对局不变量）
├── eslint.config.mjs
├── vitest.config.mjs
└── package.json
```

`js/game.js` 不引用任何 DOM API，全部交互经由 `ui.js` 暴露的 `UI.*` 接口完成，因此可在 Node 中直接单测。
